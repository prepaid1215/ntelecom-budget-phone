# SEO 실험 A·C — 2026-11-13 운영 지침

이 프로젝트의 목표는 **앤텔레콤개통방법.shop**으로 유입된 고객이 KT·LG망 알뜰폰 요금제를 비교하고 실제 신규가입 또는 번호이동을 완료하도록 돕는 것입니다.

## 현재 운영 실험

| 실험 | 주요 경로 | 상태 |
|---|---|---|
| A 검색 의도 랜딩 | `/앤텔레콤-…/` | 9개 중 색인 후보 6개. 실제 검색 색인은 별도 확인 |
| C 네이버 블로그 원문 발견 | `/indexkit/`, `/indexkit/{batch}/` | 실험군과 대조군을 보존하고 수집·색인 여부를 구분해 관측 |

**B 지역 대량페이지 실험은 2026-11-13 종료.** `/regions/` 라우트·배포·사이트맵·SEO 테스트에서 제거했습니다. `seo-lab/regions/`의 기존 검수 자료는 역사적 기록일 뿐 활성 실험이 아닙니다. 다시 자동 생성하거나 색인 제출하지 않습니다.

## 콘텐츠와 전환의 연결

- 네이버 블로그: 번호이동, 기존 휴대폰, 상품권 등 실제 궁금증을 풀어주는 정보형 글
- 인스타그램: 같은 주제를 생활 장면·카드뉴스·릴스로 재구성
- 스레드: 사용자가 공감하는 짧은 일상·질문형 글. 대놓고 판매하는 글 반복 금지
- 홈페이지: 글 주제와 **일치하는 상세페이지**를 연결하고, KT·LG망 요금제 비교와 개통 신청으로 이어지게 구성
- 핵심 성과: 검색 유입 → 상세페이지 방문 → 가입 버튼 클릭 → 확인된 실제 가입 수

세부 운영 규칙: [다채널 연계 운영 계획](../docs/channel-funnel.md).

## A의 품질 기준

- `title` 40자 이내, `description` 30~80자
- 실제 상품·혜택 조건이 검증되었고 페이지별 검색 의도가 서로 다른지 확인
- 본문 600자 이상, 내부 링크 3개 이상
- 근거가 불충분하거나 다른 페이지와 겹치면 색인 후보에서 제외

**C의 원칙:** 네이버 블로그 링크가 검색엔진에 발견될 가능성과, 실제 수집·색인 여부는 서로 다릅니다. 실험군·대조군 링크를 임의로 추가하지 않습니다.
