# 앤텔레콤개통방법.shop — 네이버 블로그·인스타그램·스레드 연계 운영

업데이트: 2026-11-13

## 목적

검색·소셜 방문자가 **KT·LG망 알뜰폰 요금제를 이해하고 비교한 뒤 실제 온라인 신규가입 또는 번호이동**까지 진행하도록 만듭니다. 콘텐츠량이나 URL 수만 늘리는 것이 목표가 아닙니다.

브랜드/사이트는 선불폰 중심의 59만모바일과 구분해 운영합니다. 고객에게는 `후불`이라는 표현보다 '알뜰폰', 'KT망', 'LG망', '요금제'를 사용합니다.

## 역할이 다른 네 채널

| 채널 | 콘텐츠 역할 | 다음 동선 |
|---|---|---|
| 스레드 | 공감·궁금증·짧은 이야기. 광고 같은 문장 반복을 피함 | 궁금한 사람에게 정보성 블로그 또는 프로필 |
| 인스타그램 | 일상 사진, 카드뉴스, 릴스. 하나의 포인트를 이미지로 소개 | 프로필의 주제별 상세 링크 |
| 네이버 블로그 | 검색자 질문에 답하는 경험·비교형 글. 요금과 혜택은 출처를 확인 | 해당 주제의 사이트 **상세페이지** |
| 앤텔레콤개통방법.shop | KT·LG망 요금제·혜택 조건 비교, 가입 전환 | 실제 개통 화면 |

사이트와 블로그 글은 처음부터 가입을 강요하지 않고, 검색 의도에 맞는 정보와 정확한 요금·혜택을 제공해야 합니다.

## 하나의 주제 → 채널별 다른 구성

예시: 다이소 상품권 요금제

1. **블로그**: "다이소 상품권 매달 5천 원? ..." — 상세한 요금제 비교, 혜택 조건, 번호이동 설명
2. **인스타그램**: 생활용품 구매 상황 → 월 5천 원 상품권 구조 → 할인과 상품권 차이 → 자세한 확인 경로 (4~5장)
3. **스레드**: 다이소 갈 때마다 예상보다 많이 사는 경험, 통신비와 생활혜택을 묶는 선택에 관한 짧은 질문
4. **사이트**: `/benefits/daiso/` — 요금 7·10·15GB, 상품권 지급 조건, 온라인 가입 버튼

기존 블로그 글: https://blog.naver.com/ntelecomhowto/224474522697

**중복 글 금지:** 블로그 원고를 인스타·스레드에 그대로 복사하거나 같은 판매 문구를 모든 채널에 반복하지 않습니다. 소재는 공유하되 문장과 형식을 채널에 맞게 새로 만듭니다.

## 링크·측정 규칙

- 사이트 메인보다 **주제별 상세페이지**를 우선 목적지로 지정합니다.
- URL은 사용자에게 한글 도메인으로 안내하되, 브라우저·검색·공유에서 Punycode로 정규화되는 현상은 정상입니다.
- 정식 UTM 예시:
  - 인스타그램: `https://앤텔레콤개통방법.shop/benefits/daiso/?utm_source=instagram&utm_medium=social&utm_campaign=daiso_benefit`
  - 스레드: `https://앤텔레콤개통방법.shop/benefits/daiso/?utm_source=threads&utm_medium=social&utm_campaign=daiso_benefit`
  - 네이버 블로그: `https://앤텔레콤개통방법.shop/benefits/daiso/?utm_source=naver_blog&utm_medium=referral&utm_campaign=daiso_benefit`
- UTM은 링크 구분을 위한 규칙입니다. GA4가 설치되어 수집되는지 확인하기 전에는 방문 수 측정이 완료됐다고 말하지 않습니다.
- 블로그 발행 URL과 날짜를 기존 구글 드라이브 `앤텔레콤개통방법.SHOP_블로그_발행관리`의 `발행관리` 탭에 기록합니다. 채널별 발행물·연결 링크는 같은 문서의 `작업일지` 또는 별도 연계관리 탭에 기록할 수 있습니다.
- 구분할 지표: 게시물 도달/클릭, 사이트 유입, 요금제 상세 조회, 가입 버튼 클릭, 실제 가입 완료. **마지막 단계는 실제 가입 실적과 대조**합니다.
- 네이버 블로그를 인스타·스레드로 자동 무단 복제·대량 발행하지 않습니다. 공식적으로 허용되는 도구와 승인된 권한을 사용합니다.

## 초기 실행 순서

1. 다이소 상세페이지 실제 도메인 반영·가입 버튼 점검

5. 다음 주제 '알뜰폰 번호이동하면 쓰던 번호 그대로 가능한가?'의 정보성 블로그와 사이트 관련 상세페이지 연결
